# Capability Cartography

Capability Cartography treats modern agent tooling as a mapped terrain: precise grids, small coordinates, route lines, and protected zones. The work should feel like an expert control-room artifact, not a social media template. Space communicates the core idea before words do: scattered modules become ordered systems, loose fragments become governed paths, and risk turns into legible structure.

The palette is restrained and technical: deep near-black, warm porcelain text, soft border lines, and a single green signal for approval or safe movement. Color is not decoration; it is status. Every mark must feel calibrated with painstaking attention, as if a senior brand systems designer spent hours testing opacity, weight, rhythm, and alignment until the whole set became quiet but unmistakably premium.

Scale carries the narrative. Large type appears only for decisive claims. Small metadata, command snippets, and slide numbers behave like evidence pinned to a diagram. The carousel should be meticulously crafted, with repeated forms and spacing that make the sequence feel like a complete campaign system rather than isolated slides.

Composition should move from disorder to control. Early slides can show fragments, drift, and duplicated surfaces; later slides should become cleaner, more centralized, and more confident. This makes the user feel the product value visually: Intertool is the control plane that turns agent capability sprawl into a governed registry.

The final result should look labored over with master-level execution. No generic gradients, no fluffy illustration, no paragraph-heavy explainers. Text is sparse and functional. The craft lives in the grid, the visual rhythm, the exactness of the modules, and the disciplined way each slide advances the same system.
