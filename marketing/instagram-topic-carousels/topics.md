# Intertool Topic Carousel Plan

## 1. Agent-Tool Sprawl

Positioning: teams have too many agent capabilities spread across tools, repos, local folders, and chat. Intertool creates one approved source of truth.

## 2. Private MCP Registry

Positioning: public MCP discovery does not solve private internal server governance. Intertool gives teams a private catalog for MCP servers and configs.

## 3. Review Before Rollout

Positioning: agent capabilities should go through an approval path before developers install and run them. Intertool adds review, status, owners, and approved install commands.

## 4. Version And Audit History

Positioning: prompts, skills, MCP servers, and internal tools need changelogs, versions, package files, and audit history attached to what people install.

## 5. Rollout And Pricing Path

Positioning: teams can start self-hosted for free, then move into managed governance, private deployment support, or enterprise rollout when the registry becomes infrastructure.
